# Icon Placeholder

Since we cannot create actual PNG images through this interface, you'll need to create an icon:

## Option 1: Create Your Own Icon (Recommended)
Create a 128x128 PNG image with a council/building theme:
- Use design tools like Figma, Canva, or Photoshop
- Represent a council/parliament building with pillars
- Use colors like blues and purples
- Save as `media/icon.png` (128x128 or 256x256)

## Option 2: Use a Placeholder
For testing, you can use any 128x128 PNG image temporarily.

## Option 3: Use an SVG-to-PNG Converter
Convert the `media/sidebar-icon.svg` to PNG:
1. Open sidebar-icon.svg in a browser
2. Take a screenshot or use an online SVG-to-PNG converter
3. Save as icon.png in the media folder

The extension will work without the icon, but it won't display properly in the marketplace.
